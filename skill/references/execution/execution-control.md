# 执行边界与继续条件

## 划定可执行范围

为每项实质工作明确目标、允许操作及其资源范围、结束时应提供的证据，以及仍待确认的影响或决策。执行者使用当前实际可用且获准的操作。简单任务可把实施和定向检查合在同一项工作中。

分别核对每项并行工作的前置输入、写入范围与集成顺序。共享写入目标、依赖未就绪或结果必须先后产生时，按依赖串行。在多代理路线中，主代理执行命令仍受[主代理职责](../roles/main-agent.md#执行要求)约束。

## 继续、调整或暂停

到达约定交付点，或发现实质偏差、未知效果及新的前置条件时，核对[阶段反馈](execution-stage-feedback.md)和后续权限。

- 现有前提仍成立且下一项工作获准时，按依赖继续。
- 需要改变范围、取舍或验收条件时，先[复核决策和执行条件](../planning/execution-decision-gate.md)，再恢复受影响的工作。
- 缺少足以决定后续的证据时，暂停依赖该证据的工作，在可核实后重新判断。仍有效的结果和独立工作可以继续使用。
