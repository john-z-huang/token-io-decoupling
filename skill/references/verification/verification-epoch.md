# 当前产物与证据时效

## 将证据关联到产物状态

- 核对每项检查的验收条件、产物版本或可辨认的状态、相关输入与适用范围。产物、依赖、验证条件或验收条件变化后，对照实际差异判断哪些检查受到影响。证据的覆盖范围或适用状态不明时，先补证再依赖其结果。

## 重新核验受影响的检查

- 实现、配置、测试或被验证的依赖发生变动时，重查受影响的行为和验收条件。文档或注释变动时，重查受影响的文档检查。文档中的可执行内容、行为约定或验收标准改变时，同时重查相关产品行为或验收证据。
- 涉及提交、分支、暂存区或历史状态的验收时，核对当前 Git 状态及其内容是否与已验证产物一致。内容一致且检查所依赖的输入未变时，沿用仍适用的内容证据。发现内容差异时，复核新增或改变的部分。
- 保留仍适用的证据。受影响的旧证据失效，其对应项从当前状态重新验证，或记录尚缺的证据。
