# Coding Workflow Responsibility Migration

[English](coding-workflow-responsibility-migration.md) | [简体中文](coding-workflow-responsibility-migration_zh_cn.md)

This development record maps the former Layer-03 route decisions and Layer-02 workflow-selection prose to the four-layer owners. Historical paths below identify source locations only; links to active owners use current paths.

| Former source responsibility | New owner | Route consumption | Retained boundary |
| --- | --- | --- | --- |
| `workflows/coding.md` Entry/Routes: preflight composition and unique route selection | [Route Entry](skill/references/coding/layer-03-workflow-checkpoints/route-entry.md) | Entry, checked at S03/M03 | Mode menu/default/invalid-input policy stays in the Mode owners; entry links the selected route. |
| Layer-02 Environment/Capability Inventory: optional Enhanced eligibility choice | [Enhanced Path Selection](skill/references/coding/layer-03-workflow-checkpoints/enhanced-path-selection.md) | S02/M02 | Generic capability evidence and Enhanced availability/state policy stay in their existing owners. |
| Layer-04 Session step: canonical store authority, reconciliation/transfer, guarded open/resume, migration eligibility, and readback routing | [Session State Resolution](skill/references/coding/layer-03-workflow-checkpoints/session-state-resolution.md) | S04/M04 before audit resolution | Authority, identity, role, firewall, schema, migration mechanics, and typed state policy stay in their L1 owners; outage never transfers authority. |
| Layer-04 Session step: audit-record reuse, fixed prompt, reply/clarification, timeout, and audit-field readback | [Session Audit Resolution](skill/references/coding/layer-03-workflow-checkpoints/session-audit-resolution.md) | S04/M04 after state resolution | Audit field/default/display semantics stay in Session Audit Visibility; state authority/schema procedures are owned by Session State Resolution and its L1 references. |

| Layer-02 Repair and route repair/decision return logic | [Repair Disposition](skill/references/coding/layer-03-workflow-checkpoints/repair-disposition.md) | S11/M13; material decisions return S01/S06 or M01/M07 | Diagnosis, authorization, repair scope, handoff, and changed-epoch verification remain in Layer-02 repair owners. |
| Layer-02 Documentation and route impact return logic | [Documentation Impact](skill/references/coding/layer-03-workflow-checkpoints/documentation-impact.md) | S12/M14 | Documentation epoch, required checks, affected-content reverification, and evidence reuse remain in Documentation and Verification Epoch. |

The complete route templates now live under `references/coding/layer-04-workflows/`; Layer-04 retains ordered scheduling, owner calls, result gates, blocks, and returns. Layer-03 owns executable task-specific decision procedures and does not redefine Layer-01/02 policy. The responsibility rows above identify the procedures moved out of route prose; route summaries consume their evidence without repeating the full procedure.
