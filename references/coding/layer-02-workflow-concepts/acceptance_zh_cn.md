# 验收检查点

[English](acceptance.md) | [简体中文](acceptance_zh_cn.md)

## 动作

1. 将 Contract 中的每个验收条件映射到最终状态的当前证据。
2. 检查修改路径、影响和文档都在已批准范围内。
3. 分开记录通过、失败、未运行、不可用、假设和用户已授权的项目。
4. 记录剩余风险，以及需要新授权或新 Contract 才能处理的后续工作。
5. 只有不存在未解决的必需项目、能力、验证边界或授权问题时，才报告 `COMPLETE`。

## 通过条件

最终报告有证据支持、准确描述范围，并明确说明限制和已授权影响。

## 边界

本检查点不隐藏失败，不把假设变成事实，也不授权新的实现、文档或 Git 工作。
