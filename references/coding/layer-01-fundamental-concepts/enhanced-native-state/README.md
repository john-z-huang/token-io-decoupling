# Enhanced Native State

[English](README.md) | [简体中文](README_zh_cn.md)

## Scope and boundary

Enhanced workflow availability, host binding, rule context, state storage, schema lifecycle, and Native authority transfer/reconciliation. It defines state authority and trusted-operation boundaries, not route selection.

## Entry

Start with availability/binding before any Enhanced operation; consult store, migration, or Native recovery owners only when triggered.
