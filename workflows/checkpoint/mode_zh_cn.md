# 执行模式检查点

[English](mode.md) | [简体中文](mode_zh_cn.md)

## 动作

1. 用户禁止子代理、子任务、独立 Session 或并行委派时，选择**单代理 Coding**。
2. 只有用户明确要求多个代理，或具体的结构收益、隔离要求或能力要求使拆分必要且被允许时，才选择**多代理 Coding**。
3. 两种条件都不存在时，默认选择单代理 Coding。
4. 如果所选模式符合已组合好的工作流，只读取该完整工作流；否则记录该模式，并按照 Coding 索引组合检查点。如果模式条件后来不再成立，停止当前切片，修改 Contract，然后重新选择。

## 通过条件

已记录且只记录一条执行模式，并且该模式要求的能力和禁止事项都得到满足。

## 边界

本检查点只选择执行路线，不决定任务架构，不授予委派权限，也不创建 Session。
