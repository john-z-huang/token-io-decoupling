# 2026-11-18 · 精简 Pi 会话账本与委派适配

## 工具与回合

- `coding_checkpoint` 提供规则与状态查询、长结果分页以及暂停和异常恢复。Agent 在对话中判断适用的 Hook 并推进任务。常规回合结束时，Pi 的 `agent_settled` 事件撤销旧 Slice。中止或仍有未决调用时进入暂停并要求读回。
- Git 请求通过 `coding_run.verificationEvidence` 附带检查回执。扩展在实际调用前核对当前内容与文档版本、证据及放行范围。仅 Git 元数据变化时，仍可复用有效的内容和文档回执。

## 会话账本

- v3 账本只保存会话与目录绑定、模式及审计、预算、已占名额、未决调用和规则指纹等恢复所需事实。任务正文留在 Pi 对话中，Slice、观察回执及证据版本留在当前运行内。
- v1/v2 快照仍可读回恢复所需事实。恢复后重新核对实际效果和写入范围。树切换继续合并会话级名额，并以最新账本中的未决调用为准，避免从旧分支重新带回已处置的调用。 [Pi 扩展说明](../docs/project/PI_EXTENSION.md) · [工作流架构](../docs/project/WORKFLOW_ARCHITECTURE.md)

## 子代理适配

- 委派采用 `@mjakl/pi-subagent@3.1.0` 的 `calls[]` 接口。每个任务以空上下文派发，按宿主实际注册的 Schema 核对模型、推理强度及必需字段。只提供旧 Schema 的同名工具会在预留名额前被拒绝。
- 移除旧版适配分支、模型覆盖补丁、专用检查脚本和部署说明。仓库改动不触及用户目录中的插件或配置。 [3.1.0 适配说明](../integrations/pi-subagent/README.md)
